# Discord Times Graphics Converter

Небольшой конвертер графики игры **Discord Times**: анимированные `.ugs`-спрайты и отдельные `.lit`-изображения можно открывать, редактировать через PNG и собирать обратно.

## Возможности

- распаковка UGS в пронумерованные PNG;
- сборка PNG обратно в UGS;
- сохранение 16 уровней прозрачности ARGB4444;
- автоматический лист предпросмотра;
- проверка размеров и последовательности кадров;
- графическое окно и интерфейс командной строки;
- защита от случайной замены существующего файла.
- проверка UGS без распаковки;
- резервная копия заменяемого UGS и быстрое открытие папки результата.
- сетка всех 64 кадров 8×8 и анимированный предпросмотр выбранной строки;
- перетаскивание PNG и папок в окно;
- импорт спрайт-листа 8×8;
- экспорт выбранного кадра, всех кадров или прозрачного спрайт-листа 8×8;
- адаптивный интерфейс для разных разрешений и масштаба Windows;
- собственная иконка приложения на основе `HeroBonus2`;
- поддержка UGS интерфейса игры с 1, 8, 50 и другим количеством кадров;
- безопасная установка UGS в игру с проверкой совместимости и резервной копией.
- отдельная вкладка LIT с адаптивным предпросмотром;
- открытие и проверка всех игровых вариантов LIT: 0, 2, 4, 6, 8 и 10;
- экспорт LIT в PNG, импорт PNG и сборка LIT с сохранением исходного типа;
- корректная обработка YCbCr, DCT-сжатия, цветности 4:2:0 и альфа-канала;
- открытие папки с LIT, выбор файла из списка и переход назад/вперёд;
- предпросмотр LIT без увеличения: оригинальный масштаб для небольших изображений и уменьшение крупных до рамки;
- перетаскивание `.lit`, папки с LIT и PNG в окно.

## Быстрый запуск в Windows

### Готовый EXE

Откройте страницу [Releases](https://github.com/Rozhko18aka/discord-times-ugs-converter/releases), скачайте `Discord-Times-Graphics-Converter.exe` из последнего выпуска и запустите его. Устанавливать Python и зависимости не требуется.

До первого официального выпуска тестовую сборку можно получить на странице **Actions → Build Windows EXE**: запустите workflow вручную и скачайте артефакт `Discord-Times-Graphics-Converter-Windows`.

### Запуск из исходного кода

1. Установите [Python 3](https://www.python.org/downloads/).
2. Установите Pillow:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Запустите `launch_converter.bat` или выполните:

   ```powershell
   python ugs_converter.py
   ```

Подробная русскоязычная инструкция находится в [README_UGS_CONVERTER.md](README_UGS_CONVERTER.md).

## Командная строка

```powershell
python ugs_converter.py extract "Hero-Knight.ugs" ".\hero_frames"
python ugs_converter.py build ".\hero_frames" ".\Hero-Knight-new.ugs"
python ugs_converter.py inspect "Hero-Knight.ugs"
python ugs_converter.py install ".\Hero-Knight-new.ugs" "C:\путь\к\игре\Graphics\Units\Hero-Knight.ugs" --yes
python ugs_converter.py lit-extract ".\Cursor-Normal.lit" ".\Cursor-Normal.png"
python ugs_converter.py lit-build ".\Cursor-Normal.png" ".\Cursor-Normal-new.lit"
python ugs_converter.py lit-inspect ".\Cursor-Normal.lit"
```

Добавьте `--force`, если разрешено заменить существующий выходной UGS.

## Формат пикселя

Канал цвета и альфа хранятся в ARGB4444. Значение на диске вычисляется так:

```text
UGS pixel = ROL16(ARGB4444, 3) XOR 0xAAAA
```

Полностью прозрачный чёрный пиксель кодируется как `0xAAAA`.

## Формат LIT

LIT хранит одно изображение в цветовом пространстве YCbCr. Ресурсы игры используют несжатые данные или блочное DCT-сжатие, иногда с цветностью 4:2:0 и отдельной альфа-плоскостью. Конвертер читает все шесть найденных вариантов и при замене PNG сохраняет тип открытого файла. Для нового непрозрачного PNG выбирается несжатый тип 4, для PNG с прозрачностью — тип 8.

Сжатые LIT являются форматом с потерями, поэтому многократная цепочка «LIT → PNG → LIT» может немного менять оттенки. Если открыть LIT и сразу сохранить его без импорта PNG, приложение копирует исходные байты без повторного сжатия.

## Проверка точности

Обратное преобразование оригинального `Hero-Knight.ugs` даёт побайтно идентичный файл. Кодирование официальных TGA-исходников эффекта `P-Ring` также даёт UGS, идентичный игровому файлу. LIT-декодер проверен на 248 игровых ресурсах всех шести вариантов.

## Правовой статус

Проект не содержит файлов игры UGS/LIT и других наборов игровых ресурсов. Исключение — иконка приложения, созданная на основе предоставленного изображения `HeroBonus2.png`. Пользователь самостоятельно отвечает за наличие прав на конвертируемые материалы.
