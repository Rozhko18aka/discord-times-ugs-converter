# UGS Converter

Конвертер спрайтов юнитов **Discord Times** между игровым форматом `.ugs` и обычными PNG.

## Быстрый запуск

Дважды щёлкните **`Запустить UGS Converter.bat`**. В окне оставлены только основные действия:

- **Открыть UGS** и **Собрать UGS**;
- **Импорт листа 8×8** и **Проверить кадры**;
- экспорт листа 8×8, выбранного кадра или всех кадров;
- замена выбранного кадра одним PNG;
- замена всех кадров PNG-файлами из выбранной папки.

При замене одного кадра новый PNG должен иметь тот же размер. Для замены всех кадров папка должна содержать ровно столько же PNG одинакового размера, сколько находится в открытом наборе. Нумерованные `frame_*.png` проверяются на пропуски.

В окно также можно перетащить один `.ugs`. Поддерживаются не только наборы юнитов из 64 кадров, но и элементы интерфейса с произвольным количеством кадров. Для таких файлов отсутствие сетки 8×8 не считается ошибкой.

Проверена совместимость с оконными ресурсами `Way_Arrows.ugs` (8 кадров), `Title_RUS.ugs`, `MM_Icons.ugs`, `MB2.ugs` (по одному кадру) и `Clock.ugs` (50 кадров). Широкие одиночные изображения при распаковке получают предпросмотр исходного размера без семи пустых столбцов.

Справа показывается сетка 8×8. Щелчок по кадру выбирает соответствующую строку анимации. Слева можно переключать строки 1–8, ставить анимацию на паузу и менять скорость.

Размер окна и ячеек сетки автоматически подстраивается под разрешение экрана и масштаб Windows. Если вертикального места недостаточно, левая панель прокручивается колёсиком мыши или полосой прокрутки — нижние кнопки остаются доступными.

В блоке **«Экспорт PNG»** доступны три варианта:

- **Выбранный кадр** — сохраняет PNG ячейки, по которой щёлкнули в сетке;
- **Все кадры** — сохраняет набор `frame_000.png`–`frame_063.png` в выбранную папку;
- **Спрайт-лист 8×8** — объединяет кадры в один PNG без промежутков, сохраняя прозрачность.

Если кадров меньше 64, незаполненные ячейки экспортируемого листа остаются прозрачными. Больше 64 кадров в лист 8×8 экспортировать нельзя. Экспорт всех кадров не удаляет файлы, поэтому программа просит выбрать другую папку, если обнаруживает лишние старые `frame_*.png`.

Программа помнит последнюю выбранную папку до закрытия окна и предлагает разумное имя нового UGS. После завершения можно сразу открыть папку результата. При подтверждённой замене существующего UGS сначала автоматически создаётся резервная копия `.bak` (при необходимости `.bak.1`, `.bak.2` и далее).

### Требования к спрайт-листу

- один PNG содержит ровно 8 столбцов и 8 строк;
- ширина PNG должна делиться на 8 без остатка;
- высота PNG должна делиться на 8 без остатка;
- между кадрами не должно быть полей или промежутков, если они не являются частью самих кадров.

Порядок импорта: первая строка даёт `frame_000`–`frame_007`, вторая — `frame_008`–`frame_015` и так далее.

### Установка из командной строки

Команда установки сохранена для консоли. Она блокируется, если новый и игровой UGS имеют разное количество кадров или разные размеры. Оригинал сохраняется рядом как `имя.ugs.bak`; существующие копии не перезаписываются.

Редактируйте только файлы `frame_*.png`. `preview_sheet.png` служит для просмотра и при сборке не используется.

> PNG, распакованные первой версией конвертера с пометкой `BGR565` в `ugs_info.json`, имеют неверные цвета. Исходный UGS необходимо распаковать заново. Если все кадры уже полностью заменены собственными PNG, старый `ugs_info.json` можно удалить.

## Правила подготовки кадров

- Все PNG в одном наборе должны иметь одинаковый размер.
- Цвет и прозрачность берутся из RGBA-каналов PNG. Формат игры поддерживает 16 уровней каждого канала, включая 16 уровней альфы.
- При сборке каналы переводятся из 8 бит в 4 бита, как в оригинальном конвертере игры. Поэтому возможна небольшая неизбежная потеря оттенков.
- Нумерация должна начинаться с нуля и идти без пропусков.
- Если рядом находится созданный при распаковке `ugs_info.json`, программа сверяет с ним количество и размер кадров.
- Для стандартного героя требуется 64 кадра размером 64×64: 8 строк направлений по 8 фаз анимации.
- Перед подменой игрового файла сохраните его резервную копию.

## Командная строка

```powershell
python .\ugs_converter.py extract "C:\путь\Hero-Knight.ugs" ".\hero_frames"
python .\ugs_converter.py build ".\hero_frames" ".\Hero-Knight-new.ugs"
python .\ugs_converter.py inspect "C:\путь\Hero-Knight.ugs"
python .\ugs_converter.py install ".\Hero-Knight-new.ugs" "C:\путь\к\игре\Graphics\Units\Hero-Knight.ugs" --yes
```

Для замены уже существующего выходного файла добавьте `--force`:

```powershell
python .\ugs_converter.py build ".\hero_frames" ".\Hero-Knight-new.ugs" --force
```

## Формат

Каждый кадр содержит 16-битные little-endian ширину и высоту. Пиксель сначала представляется как ARGB4444, затем его 16-битное значение циклически сдвигается влево на 3 бита и складывается по XOR с `0xAAAA`. Полностью прозрачный чёрный пиксель в результате имеет значение `0xAAAA`.
