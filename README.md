# Discord Times UGS Converter

Небольшой конвертер анимированных спрайтов игры **Discord Times** между игровым форматом `.ugs` и отдельными PNG-кадрами.

## Возможности

- распаковка UGS в пронумерованные PNG;
- сборка PNG обратно в UGS;
- сохранение 16 уровней прозрачности ARGB4444;
- автоматический лист предпросмотра;
- проверка размеров и последовательности кадров;
- графическое окно и интерфейс командной строки;
- защита от случайной замены существующего файла.
- проверка UGS без распаковки;
- резервная копия заменяемого UGS и быстрое открытие папки результата.

## Быстрый запуск в Windows

1. Установите [Python 3](https://www.python.org/downloads/).
2. Установите Pillow:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Запустите `launch_converter.bat` или выполните:

   ```powershell
   python ugs_converter.py
   ```

Подробная русскоязычная инструкция находится в [README_UGS_CONVERTER.md](README_UGS_CONVERTER.md).

## Командная строка

```powershell
python ugs_converter.py extract "Hero-Knight.ugs" ".\hero_frames"
python ugs_converter.py build ".\hero_frames" ".\Hero-Knight-new.ugs"
python ugs_converter.py inspect "Hero-Knight.ugs"
```

Добавьте `--force`, если разрешено заменить существующий выходной UGS.

## Формат пикселя

Канал цвета и альфа хранятся в ARGB4444. Значение на диске вычисляется так:

```text
UGS pixel = ROL16(ARGB4444, 3) XOR 0xAAAA
```

Полностью прозрачный чёрный пиксель кодируется как `0xAAAA`.

## Проверка точности

Обратное преобразование оригинального `Hero-Knight.ugs` даёт побайтно идентичный файл. Кодирование официальных TGA-исходников эффекта `P-Ring` также даёт UGS, идентичный игровому файлу.

## Правовой статус

Проект не содержит файлов игры, игровых изображений или иных ресурсов Discord Times. Пользователь самостоятельно отвечает за наличие прав на конвертируемые материалы.
