# UGS Converter

Конвертер спрайтов юнитов **Discord Times** между игровым форматом `.ugs` и обычными PNG.

## Быстрый запуск

Дважды щёлкните **`Запустить UGS Converter.bat`**. В открывшемся окне доступны две операции:

- **Распаковать UGS → PNG** — создаёт `frame_000.png`, `frame_001.png` и остальные кадры, общий `preview_sheet.png` и файл сведений `ugs_info.json`.
- **Собрать PNG → UGS** — собирает все `frame_*.png` из выбранной папки в порядке их номеров.
- **Проверить UGS** — проверяет структуру файла и показывает количество и размер кадров, размер файла и SHA-256.

Программа помнит последнюю выбранную папку до закрытия окна и предлагает разумное имя нового UGS. После завершения можно сразу открыть папку результата. При подтверждённой замене существующего UGS сначала автоматически создаётся резервная копия `.bak` (при необходимости `.bak.1`, `.bak.2` и далее).

Редактируйте только файлы `frame_*.png`. `preview_sheet.png` служит для просмотра и при сборке не используется.

> PNG, распакованные первой версией конвертера с пометкой `BGR565` в `ugs_info.json`, имеют неверные цвета. Исходный UGS необходимо распаковать заново. Если все кадры уже полностью заменены собственными PNG, старый `ugs_info.json` можно удалить.

## Правила подготовки кадров

- Все PNG в одном наборе должны иметь одинаковый размер.
- Цвет и прозрачность берутся из RGBA-каналов PNG. Формат игры поддерживает 16 уровней каждого канала, включая 16 уровней альфы.
- При сборке каналы переводятся из 8 бит в 4 бита, как в оригинальном конвертере игры. Поэтому возможна небольшая неизбежная потеря оттенков.
- Нумерация должна начинаться с нуля и идти без пропусков.
- Если рядом находится созданный при распаковке `ugs_info.json`, программа сверяет с ним количество и размер кадров.
- Для стандартного героя требуется 64 кадра размером 64×64: 8 строк направлений по 8 фаз анимации.
- Перед подменой игрового файла сохраните его резервную копию.

## Командная строка

```powershell
python .\ugs_converter.py extract "C:\путь\Hero-Knight.ugs" ".\hero_frames"
python .\ugs_converter.py build ".\hero_frames" ".\Hero-Knight-new.ugs"
python .\ugs_converter.py inspect "C:\путь\Hero-Knight.ugs"
```

Для замены уже существующего выходного файла добавьте `--force`:

```powershell
python .\ugs_converter.py build ".\hero_frames" ".\Hero-Knight-new.ugs" --force
```

## Формат

Каждый кадр содержит 16-битные little-endian ширину и высоту. Пиксель сначала представляется как ARGB4444, затем его 16-битное значение циклически сдвигается влево на 3 бита и складывается по XOR с `0xAAAA`. Полностью прозрачный чёрный пиксель в результате имеет значение `0xAAAA`.
